# Leads folder rules

These rules apply to everything in this folder.

- **These are made-up practice people.** Nobody in `leads.csv` is real. We use them to practise planning and writing emails.
- **Never add real people or real email addresses.** Do not add a real name, contact or address, even for testing.
- **Every row needs a consent value.** Do not add a row with an empty `consent` column.
- **Never change the @example.com addresses.** Every email must end in `@example.com`. This domain is reserved and can never receive mail, so no real person is ever emailed.
